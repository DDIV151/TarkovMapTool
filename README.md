# TarkovMapTool - 逃离塔科夫外置地图定位工具


一个轻量级的 Windows 桌面应用程序，用于在悬浮窗上显示《逃离塔科夫》游戏内的玩家位置。通过解析游戏截图文件名中的坐标信息，结合可自定义的地图图片，实现精准的地图定位与方向指示。

⚠️ 注意：本工具仅解析截图文件名中的坐标，不读取游戏内存，不修改游戏客户端，符合游戏规则。

✨ 主要特性
悬浮地图窗口：无边框、置顶显示，可自由拖动和调整大小，支持锁定防止误触。

实时定位：通过监控截图文件夹，自动读取最新截图中的玩家坐标与朝向，并在地图上标记位置和视角方向箭头。

多地图支持：内置 12 张塔科夫地图，一键切换。

灵活校准：

支持在浮窗或独立预览窗口中多选点校准（≥2 个点），精确建立游戏坐标与地图图片的映射关系。

当校准点达到 3 个及以上时，自动使用最小二乘仿射拟合，有效修正地图旋转、缩放不均匀等问题，大幅提升全图定位精度。

全局热键：可自定义截图刷新、地图缩放快捷键，无需切换窗口。

地图预览：独立预览窗口，支持缩放、拖动，鼠标悬停实时显示游戏坐标，方便校准。

设置持久化：所有配置（截图目录、快捷键、窗口位置）自动保存，启动即用。

🖥️ 运行环境
Windows 7 及以上（推荐 Windows 10/11）

.NET Framework 4.8（大多数 Windows 10/11 已预装）

📥 下载与安装
前往 Releases 页面 下载最新版本的 TarkovMapTool.zip。

解压到任意目录，确保 maps 文件夹与 TarkovMapTool.exe 在同一位置。

双击 TarkovMapTool.exe 运行即可（无需安装）。

首次运行：

程序会要求选择截图保存目录（通常为 文档\Escape from Tarkov\Screenshots）。

地图图片需自行放入 maps 文件夹，文件名需与配置文件 mapconfig.json 中对应（默认提供了常用地图名，但图片需要自己准备）。

🔧 使用教程
基本操作
设置截图目录：点击主界面“浏览...”按钮，选择塔科夫截图文件夹。

启动浮窗：点击“启动地图浮窗”，会在之前保存的位置弹出一个无边框地图窗口。

切换地图：点击下方地图按钮（如“海关”、“森林”），浮窗内容同步切换。

锁定/解锁：浮窗打开后，点击“解锁”可拖动浮窗或调整大小；点击“锁定”保存位置。

缩放地图：使用全局快捷键（需先设置）或直接在主界面按快捷键可放大/缩小浮窗中的地图视图。

地图校准（关键步骤）
为了精准定位，必须为每张地图进行校准。校准需要至少 2 个已知游戏坐标的特征点（例如地图边界上的明显建筑）。

方法一：在预览窗口校准

点击“预览地图”打开独立预览窗口。

在游戏中走到一个已知坐标的地点，记录下游戏坐标（可通过截图文件名获取，或使用其他辅助工具）。

点击“添加校准点”，输入准确的游戏坐标，然后在预览地图上左键点击对应的像素位置。

重复上述步骤，添加至少 2 个点（点越多、分布越均匀，整体精度越高）。

点击“完成校准”，程序自动计算仿射矩阵，立即生效。

方法二：在浮窗中校准

启动浮窗后，同样可使用“添加校准点”按钮在浮窗上直接标记。

快捷键设置
截图触发快捷键：按下后强制从最新截图更新位置。

放大/缩小快捷键：调整浮窗中地图的缩放级别。

设置方法：点击对应按钮，在弹出的窗口中按下组合键即可。

⚙️ 配置文件说明
mapconfig.json：存储每张地图的校准数据（仿射矩阵）。校准完成后自动更新，也可手动修改。删除该文件会恢复默认未校准状态。

user.config（自动生成）：保存截图目录、快捷键、窗口位置等用户设置。

🗺️ 准备地图图片
本工具不自带地图图片，你需要自行获取合适的地图图片（如从社区 Wiki 下载），并放置于 maps 文件夹中。图片格式支持 .png，文件名需与 mapconfig.json 中的 FileName 字段匹配（默认配置列出了 12 张官方地图的名称，但你需要自己提供图片文件）。
